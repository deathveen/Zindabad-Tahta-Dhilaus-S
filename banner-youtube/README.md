# Banner YouTube — Faedah Harian

- `banner-youtube-2560x1440.png` — file siap unggah (ukuran resmi YouTube 2560×1440, < 6 MB).
- `pratinjau-safe-area.png` — pratinjau dengan garis area aman TV / desktop / tablet / HP.
- `banner.html` — sumber desain. Ubah teks/warna di sini lalu render ulang
  (buka di browser ukuran 2560×1440 dan screenshot, atau pakai Playwright).

Palet & font mengikuti panduan visual akun: krem kertas `#F4EFE6`, tinta `#1F1B16`,
hijau zaitun `#3E5641`, emas `#B08D57`; Fraunces, Schibsted Grotesk, Amiri.

Cara pasang: YouTube Studio → Kustomisasi → Branding → Gambar banner → Unggah.
