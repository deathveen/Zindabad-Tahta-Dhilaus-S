# SOP Pembuatan Animasi Reels

Catatan semua keputusan dan alur kerja pembuatan video animasi vertikal (Reels/TikTok/Shorts)
untuk konten renungan Islami dan psikologi. Dokumen ini jadi acuan tetap; ubah di sini kalau ada
keputusan baru.

---

## 1. Ringkasan

| Hal | Keputusan |
|---|---|
| Format | Vertikal 9:16, 1080×1920, 30 fps, durasi mengikuti VO (biasanya 55–95 detik) |
| Gaya visual | **Gaya B**: kepala bulat, badan = jubah (bentuk lonceng lembut), tangan dan kaki pendek |
| Narator | **Rifda** (رِفْدَة), muncul hanya saat dibutuhkan |
| Pengisi suara | **Vonya**: suara anak, sedikit imut, dan tidak diubah nadanya |
| Musik | Instrumental buatan sendiri, lembut dan hangat |
| SFX | Hanya di adegan yang membutuhkan |
| Palet warna | Menyesuaikan isi konten per babak; warna Rifda dan gaya teks tetap |
| Akun | **Faedah Harian** · `@faedahharian.official` (lihat Bagian 9) |
| Ajakan follow | "Follow @faedahharian.official, teman belajar & pengingat harianmu" |

Contoh hasil: `seratus-bintang-satu-batu.mp4`. Lembar desain karakter: `karakter/lembar-desain.png`.

## 2. Sistem karakter

### 2.1 Gaya dasar (dikunci untuk semua video)
- Kepala bulat besar, wajah sederhana: dua mata bulat dengan kilau, pipi merah muda, mulut satu garis.
- Badan adalah jubahnya: satu bentuk lembut seperti lonceng. Tidak ada leher dan pinggang yang kaku.
- Tangan berupa lengan baju bulat dengan telapak tangan bulat; kaki berupa oval kecil di bawah jubah.
- Warna kulit `#EFC7A5`, garis/tinta `#2A2233`.

Alasan memilih gaya ini: gaya berjubah realistis terlihat aneh saat sujud karena jubahnya kaku,
sedangkan stikman terasa terlalu biasa. Pada gaya B, pose sulit seperti sujud cukup diubah bentuk
badannya, tanpa perlu menggambar lipatan kain.

### 2.2 Kostum menyesuaikan konteks
Gaya tubuh tidak pernah berubah; yang berganti hanya pakaian dan properti ("lemari kostum"):

| Konteks | Kostum |
|---|---|
| Rumah / masa kini | Kaos, sarung kotak-kotak, kopiah hitam |
| Ibadah | Jubah putih/krem, kopiah putih, sajadah |
| Perang | Zirah rantai, helm, perisai, tombak |
| Pasar / dagang | Jubah cokelat, celemek, sorban, keranjang |
| Kisah masa lalu | **Siluet tanpa wajah**, dengan cahaya tepi |

Konteks harus masuk akal: jangan sampai kisah perang memakai baju rumah.

### 2.3 Pose kunci
Pose penting digambar satu per satu, lalu animasi bergerak halus di antaranya:
- **Shalat:** berdiri (tangan bersedekap), rukuk (kepala sedikit menunduk), sujud (badan jadi gundukan bulat, dahi menempel di sajadah), duduk.
- **Umum:** diam, berjalan, menunjuk, melambai, kaget, sedih, berpikir, berdoa.

### 2.4 Rifda (narator)

| Atribut | Nilai |
|---|---|
| Nama | Rifda, ditulis **رِفْدَة** (artinya "pemberian/pertolongan") |
| Kerudung | Pink `#F29BB8` |
| Jubah | Ungu muda `#B9A6E0` |
| Label nama | Kapsul pink bertuliskan رِفْدَة, muncul saat ia pertama tampil |
| Suara | Vonya |

**Kapan Rifda muncul:**
- Pembuka (opsional): melempar pertanyaan ke penonton.
- Pindah dari cerita ke dalil/studi: mengenalkan sumber.
- Menjelaskan poin sulit: menunjuk diagram atau kartu.
- Meluruskan (misalnya hadis lemah): ekspresi "tunggu dulu".
- Penutup: refleksi dan ajakan follow.

**Kapan Rifda tidak muncul:** di tengah adegan kisah, supaya cerita tidak terganggu.

**Pose dan ekspresi:** senyum, berpikir, menunjuk, menjelaskan (tangan terangkat), kaget,
sedih/empati, melambai, dan tangan di dada (adab saat menyebut dalil). Masuk dan keluar dari sisi
layar dengan gerakan halus.

**Bicara:** saat VO berbicara dan Rifda tampil, mulutnya bergerak mengikuti keras-pelan suara Vonya
dan matanya berkedip alami.

## 3. Aturan adab dan sumber (wajib)

1. **Nabi, para Nabi, dan malaikat tidak pernah digambar.** Mereka diwakili cahaya, teks, atau sudut pandang.
2. **Sahabat dan orang saleh terdahulu** digambar sebagai siluet tanpa wajah.
3. **Teks Arab** (ayat, hadis, doa) selalu disalin dari sumber terverifikasi, tidak pernah ditulis
   dari ingatan AI. Teks dicek ulang huruf dan harakatnya sebelum render final.
4. **Hadis** selalu ditampilkan dengan perawi dan status sanadnya (shahih, hasan, dha'if, dan seterusnya) serta penilainya.
   Kalau dha'if, sampaikan dengan jujur, seperti pada contoh referensi.
5. **Studi ilmiah** ditulis lengkap: penulis, tahun, dan jurnal. Temuannya tidak dilebih-lebihkan;
   grafik ilustratif diberi label "ilustrasi".
6. **Ragu = tanya.** Kalau sumber atau status tidak jelas, tanyakan ke pemilik konten. Jangan ditebak.
7. **Karakter dan gaya harus orisinal.** Jangan meniru karakter atau gambar kreator lain.

## 4. Alur kerja (dari VO sampai video jadi)

### Tahap 1: Kirim bahan
Pemilik konten mengirim:
- **File VO** dari Vonya (format apa pun: WhatsApp, voice memo, mp3, wav, m4a).
- **Teks naskah yang dibaca** (wajib, supaya caption dan lafaz Arab tepat).
- Sumber dalil/studi kalau ada (nomor hadis, surah:ayat, judul studi).
- Musik sendiri (opsional; kalau tidak ada, dibuatkan instrumental).

### Tahap 2: Olah VO
- Bersihkan dengung dan desis ruangan, redam bunyi "s" yang tajam, perjelas suara, dan ratakan volume.
- **Jernihkan dan percepat VO menjadi 1,25×** sekaligus (`scripts/prep_vo.sh`; `atempo` menjaga nada).
- **Potong jeda sunyi** yang lebih dari 0,45 detik menjadi 0,28 detik (otomatis di `prep_vo.sh`).
- **Jangan ubah nada suara Vonya.**
- Buang kalimat yang salah baca atau diulang (pemilik konten memberi tahu bagian mana).
- Cocokkan teks naskah dengan suara: setiap kalimat mendapat waktu mulai dan selesai.
  Anak-anak membaca dengan jeda panjang dan tempo tidak rata; adegan mengikuti jeda VO, bukan sebaliknya.

### Tahap 3: Analisis isi dan verifikasi sumber
- Petakan struktur: **pembuka → cerita/perumpamaan → dalil/studi → penjelasan → penutup + ajakan follow**.
- Tandai kata kunci yang diberi warna (ditulis `*kata*` di naskah caption).
- Verifikasi semua dalil dan studi sesuai Bagian 3.
- Tentukan kalimat mana yang diucapkan Rifda dan mana yang menjadi adegan cerita.

### Tahap 4: Storyboard (titik persetujuan)
- Daftar adegan dengan waktu, perumpamaan visual utama, palet per babak, kostum, dan kapan Rifda muncul.
- Disertai sketsa beberapa frame kunci.
- **Pemilik konten menyetujui atau merevisi di sini.** Revisi paling murah di tahap ini.

### Tahap 5: Animasi
- Semua gerakan sinkron dengan VO: caption muncul per kata sesuai ucapan, dan adegan berganti di jeda kalimat.
- Gerak halus: easing, kamera melayang pelan, transisi zoom-blur antar babak, teks berefek pegas.
- Pakai komponen tetap: karakter, kostum, latar, kartu dalil/studi, timbangan, caption, judul.

### Tahap 6: Musik dan SFX
- Musik instrumental lembut (piano, petikan senar) yang mengikuti suasana babak.
- Musik **otomatis mengecil saat VO berbicara** (ducking), supaya suara Vonya yang ringan tetap jelas.
- SFX hanya di momen penting: benda jatuh, transisi, munculnya dalil, momen emosional. Jangan di setiap gerakan.
- **Pengecualian: hook (detik awal) wajib padat SFX** (boom, pop, ding) + getar/kilat layar, karena VO pembuka cenderung lemas. Musik baru masuk setelah hook.

### Tahap 7: QC (pemeriksaan)
Lihat checklist di Bagian 6.

### Tahap 8: Render dan kirim
MP4 1080×1920, H.264 + AAC, kerasnya -14 LUFS, puncak di bawah -1 dBTP.

## 5. Palet warna per suasana

Palet dipilih per babak **sesuai isi**. Pilar konten **tidak punya warna tetap**: kisah di gurun
memakai warna pasir walaupun pilarnya Aqidah/Kisah. Warna Rifda (`#F29BB8`, `#B9A6E0`) dan gaya
teks tidak berubah.

| Suasana | Arah warna |
|---|---|
| Kisah malam, renungan | Biru tua + emas |
| Peringatan, azab, bahaya | Merah gelap + abu-abu |
| Rahmat, harapan, ampunan | Krem + cahaya hangat |
| Psikologi, sains | Ungu tua + kuning amber |
| Kehidupan sehari-hari | Pastel hangat |
| Sedih → bangkit | Warna memudar → fajar oranye-merah muda |

Teks caption: putih, kata kunci berwarna amber `#FFC24B`, dengan bayangan lembut.

## 6. Checklist QC sebelum kirim

- [ ] Caption cocok kata per kata dengan ucapan Vonya
- [ ] Teks Arab dicek ulang dengan sumber (huruf dan harakat)
- [ ] Status hadis dan sumber studi tercantum dan benar
- [ ] Nabi/malaikat tidak digambar; sahabat/orang saleh berupa siluet
- [ ] Kostum sesuai konteks cerita
- [ ] Rifda hanya muncul di momen yang ditentukan, mulutnya bergerak saat bicara
- [ ] Tidak ada teks di area yang tertutup UI Reels (atas ±120 px, bawah ±250 px, kanan ±120 px)
- [ ] Suara Vonya jelas di atas musik; SFX tidak berlebihan
- [ ] Kerasnya -14 LUFS, tidak ada clipping
- [ ] Ajakan follow ada di penutup

---

## 7. Tips rekaman untuk Vonya

- Rekam di ruangan kecil yang banyak kain (misalnya kamar dengan lemari baju). Hindari kamar mandi atau ruangan kosong.
- Jarak HP ke mulut sekitar satu jengkal, sedikit menyamping supaya napas tidak "meletup".
- Baca per paragraf dengan jeda satu detik sebelum lanjut.
- Kalau salah, ulangi kalimatnya saja tanpa berhenti merekam.
- Format apa pun boleh.

## 8. Teknis

### File di folder `video/`

| File | Fungsi |
|---|---|
| `render.html` | Mesin animasi canvas; `draw(T)` menggambar satu frame pada detik T |
| `render.js` | Render semua frame lewat Playwright lalu encode dengan ffmpeg (paralel) |
| `preview.js` | Render beberapa frame ke PNG untuk dicek |
| `dump_events.js` | Ekspor daftar event SFX dari animasi ke JSON |
| `audio.py` | Mix musik + SFX (ducking, low-pass sesuai suasana) |
| `karakter/sheet.html` | Lembar desain karakter gaya B |
| `karakter/shot.js` | Render lembar desain ke PNG |

### Perintah

```bash
node video/preview.js out_dir 3 12 24        # cek frame pada detik tertentu
node video/dump_events.js video/render.html events.json
python3 video/audio.py events.json musik.mp3 mix.wav
node video/render.js video_tanpa_audio.mp4 4  # 4 proses paralel
ffmpeg -i video_tanpa_audio.mp4 -i mix.wav -c:v copy \
  -af "loudnorm=I=-14:TP=-1.5:LRA=11" -c:a aac -b:a 192k -shortest final.mp4
node video/karakter/shot.js video/karakter/sheet.html lembar.png
```

### Keterbatasan lingkungan cloud
- Layanan TTS dan unduhan model transkripsi (Whisper, dan lain-lain) diblokir jaringan container cloud.
  Karena itu **teks naskah wajib disertakan** bersama VO. Kalau ingin transkripsi otomatis,
  jalankan alur ini di komputer sendiri lewat Claude Code.
- File musik dari luar tidak disimpan di repo, hanya tertanam di video hasil.

## 10. Skill otomatis

Alur di dokumen ini sudah dijadikan skill **`animasi-faedah-harian`**
(`.claude/skills/animasi-faedah-harian/`). Kirim VO (dan naskah bila ada), lalu skill
menjalankan: transkripsi → cek dalil → storyboard (persetujuan) → kerangka episode → adegan →
cek frame → render final (persetujuan) → simpan ke `main`.

- Transkripsi VO kini bisa dilakukan di cloud (Whisper medium dari GitHub Releases), jadi teks
  naskah tidak lagi wajib, tapi tetap disarankan untuk istilah Arab.
- Mesin bersama: `video/engine/lib.js`. Contoh episode yang disetujui: `video/ep02/`.
