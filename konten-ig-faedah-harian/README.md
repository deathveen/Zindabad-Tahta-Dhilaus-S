# Konten IG — Faedah Harian (Dakwah Tanpa Muka)

Folder ini berisi bahan konteks untuk akun Instagram dakwah *faceless*
(tanpa menampilkan wajah) dengan format **satu faedah per hari**.

Sumber utama materinya adalah kitab-kitab yang sudah dikaji Zinda
(lihat `data.js` dan `copy writing buku/penjelasan buku buku.docx`).
Itu pembeda akun ini: setiap faedah **punya rujukan kitab yang jelas**,
bukan kutipan motivasi tanpa sumber.

## Isi folder

| File | Isinya |
|------|--------|
| `01-identitas-akun.md` | Posisi akun, persona, target audiens, gaya bahasa, ide nama & bio |
| `02-pilar-konten.md` | 7 pilar konten + rotasi mingguan, dipetakan ke kitab yang sudah dikaji |
| `03-format-dan-template.md` | Template carousel, single post, reels tanpa muka, story, caption, hashtag |
| `04-bank-faedah.md` | 55 bibit faedah siap olah, lengkap dengan dalil & rujukan |
| `05-panduan-visual.md` | Warna, font, ide visual & B-roll tanpa wajah, rambu-rambu gambar |
| `06-kalender-30-hari.md` | Rencana posting 30 hari pertama |
| `07-prompt-ai.md` | Prompt siap pakai kalau mau minta bantuan AI menyusun konten |
| `08-checklist-amanah-ilmiah.md` | Cek sebelum posting: dalil, derajat hadits, adab berbeda pendapat |

## Cara pakai singkat

1. Baca `01` dan `02` sekali untuk pegang arah akun.
2. Tiap hari ambil satu faedah dari `04` (atau ikuti `06`).
3. Tuangkan ke salah satu template di `03`, desain pakai `05`.
4. **Wajib** lewati `08` sebelum posting.
5. Kalau pakai AI, tempel isi `07` + file `01`–`04` sebagai konteks.

> Catatan: nomor hadits mengikuti penomoran yang umum dipakai
> (Bukhari versi Fathul Bari, Muslim versi Fu'ad Abdul Baqi). Tetap cocokkan
> lagi dengan kitab/aplikasi yang kamu pegang sebelum diposting.
