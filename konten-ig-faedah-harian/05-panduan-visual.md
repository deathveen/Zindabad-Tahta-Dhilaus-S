# 05 — Panduan Visual (Tanpa Wajah)

## Prinsip

1. **Ilmunya yang tampil, bukan orangnya.** Tidak ada wajah pengelola.
2. **Konsisten** — orang harus mengenali post akun ini tanpa membaca nama.
3. **Tenang & lapang** — banyak ruang kosong, teks tidak berdesakan.
4. **Mudah dibaca di HP** — teks utama minimal 40 px di kanvas 1080 px.

## Font

- **Judul (Latin)**: Bricolage Grotesque (sudah dipakai di situs) atau Fraunces.
- **Isi (Latin)**: Schibsted Grotesk / Inter.
- **Arab**: *Amiri* (naskhi klasik, harakat rapi) atau *Scheherazade New*.
  Untuk ayat Al-Qur'an, paling aman pakai font **mushaf Utsmani**
  (KFGQPC Uthmanic Script) supaya rasm & harakatnya tepat.
- Semua font di atas gratis (Google Fonts / King Fahd Complex).

## Tata letak carousel

```
┌──────────────────────────┐
│ LABEL PILAR       01/07  │  ← kecil, warna label
│                          │
│                          │
│   JUDUL BESAR            │  ← maks. 8 kata
│   DUA BARIS              │
│                          │
│                          │
│ @handle         geser →  │  ← kecil, konsisten
└──────────────────────────┘
```

- Margin minimal 80 px di semua sisi.
- Teks Arab di tengah, ukuran 1,3–1,5× teks Latin.
- Nomor slide di pojok kanan atas.
- Slide terakhir selalu sama polanya: sumber kitab + CTA + handle.

## Ide visual tanpa wajah

Aman dan relevan:
- Tangan membuka kitab / menulis dengan pena (rekam sendiri, wajah di luar frame).
- Close-up halaman kitab kuning, mushaf, rak kitab, meja belajar.
- Tasbih, sajadah, cangkir teh di samping kitab.
- Langit subuh, hujan di jendela, jalan setapak, pepohonan.
- Tipografi murni di atas tekstur kertas.
- Ikon/ilustrasi geometris (pola islami, bintang segi delapan).

## Rambu-rambu gambar

- ❌ **Jangan pernah** menggambarkan Nabi ﷺ, para nabi, atau sahabat
  dalam bentuk gambar/ilustrasi/AI — termasuk siluet.
- ❌ Hindari gambar AI yang menampilkan manusia/hewan secara realistis —
  banyak ulama melarang gambar makhluk bernyawa, dan akun faceless
  sebaiknya konsisten menghindarinya.
- ❌ Jangan letakkan teks ayat di atas gambar yang tidak pantas
  (orang tidak menutup aurat, tempat kotor, dsb).
- ❌ Hindari musik di reels. Ganti dengan murattal, suara alam, atau voice-over.
- ✅ Pakai stok bebas royalti (Pexels, Unsplash, Pixabay) atau rekam sendiri.
- ✅ Kalau pakai murattal qari tertentu, sebutkan nama qarinya di caption.

## Alat yang bisa dipakai

- **Canva** — template carousel (buat 1 master per pilar, tinggal duplikat).
- **CapCut** — reels teks + murattal, auto caption.
- **Figma** — kalau ingin template lebih presisi.
- Simpan file master di folder ini nanti, misalnya `konten-ig-faedah-harian/template/`.
